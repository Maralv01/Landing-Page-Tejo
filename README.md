# 🥏 MECHA-COMMERCE

**MECHA-COMMERCE** es una landing page e-commerce inspirada en el deporte del **tejo o turmequé**, una práctica tradicional colombiana con más de 500 años de historia y origen asociado a Turmequé, Boyacá.donde el objetivo es reventar la **MECHA**  
El proyecto busca promover la compra de productos para practicar tejo mientras aporta valor cultural al visibilizar una tradición reconocida como parte de la identidad colombiana. 

## ✨ ¿Qué hace este proyecto?

Esta aplicación permite explorar productos relacionados con el tejo, agregarlos a un carrito de compras y simular una experiencia de compra directamente desde el navegador, sin necesidad de backend.  
Toda la lógica funciona en el frontend usando **HTML**, **CSS**, **JavaScript**, **Bootstrap** y **localStorage** para guardar el estado del carrito entre recargas.

## 🎯 Objetivo

Crear una experiencia web atractiva, moderna e interactiva que combine:
- Comercio electrónico básico en frontend.
- Diseño visual llamativo para una hackathon.
- Rescate cultural del tejo o turmequé, deporte nacional colombiano. [web:3][web:10]

## 🛠 Tecnologías usadas

- **HTML5** para la estructura de la landing page.
- **CSS3** para estilos personalizados.
- **JavaScript** para la lógica de productos, carrito y renderizado dinámico.
- **Bootstrap** para el diseño responsive, cards de productos y componentes del carrito.
- **localStorage** para almacenar el carrito de compras en el navegador.

## 🧩 Funcionalidades principales

- Visualización de productos en **cards responsivas**.
- Botón para **agregar productos al carrito**.
- Persistencia del carrito usando **localStorage**.
- Cálculo dinámico de cantidades y total de compra.
- Interfaz amigable y moderna pensada para desktop y mobile.
- Sección hero con efecto visual inspirado en Apple para mostrar una **cancha de tejo en rotación interactiva**.

## 🍎 Efecto visual destacado

Uno de los elementos más llamativos del proyecto es una animación estilo Apple construida con **HTML, CSS y JavaScript**, donde una cancha de tejo rota o responde al movimiento para generar una experiencia más inmersiva y moderna.  
Este recurso ayuda a que la landing no sea solo un catálogo, sino una experiencia visual memorable dentro de la hackathon.

## 🛒 ¿Cómo funciona el carrito?

El carrito de compras se gestiona completamente en el frontend:
1. El usuario selecciona un producto.
2. JavaScript agrega el producto al carrito.
3. La información se guarda en **localStorage**.
4. Al recargar la página, los productos permanecen almacenados.
5. Bootstrap ayuda a mostrar el carrito de forma ordenada y responsive.

## 🌎 Inspiración cultural

El tejo, también conocido como **turmequé**, tiene raíces precolombinas y está ligado históricamente a Turmequé, Boyacá. 

Además de ser considerado el deporte nacional de Colombia, también ha sido reconocido como patrimonio cultural, lo que lo convierte en una excelente inspiración para una propuesta digital con identidad local.
